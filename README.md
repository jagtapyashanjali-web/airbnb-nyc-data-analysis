# Airbnb NYC Data Analysis

## About the Project
This project explores Airbnb listing data for New York City to understand pricing trends, 
popular neighborhoods, and host activity. The goal was to practice real-world data analysis 
and visualization using Python.

## Tools Used
- Python
- Pandas
- Seaborn
- Google Colab

## What I Did
- Cleaned and prepared the raw Airbnb dataset for analysis
- Explored pricing patterns across different NYC neighborhoods
- Visualized relationships between room type, price, and availability
- Identified trends in host activity and listing distribution

## Key Insights
- Certain neighborhoods consistently have higher average listing prices
- Room type has a noticeable impact on pricing
- A small number of hosts manage a large share of listings

## How to Run
1. Clone this repository
2. Open the notebook in Google Colab or Jupyter Notebook
3. Run the cells step by step to reproduce the analysis
